Эта курсовая работа включает в себя создание информационной системы для автосервиса. Выполняют работу Бабкевич Богдан Михайлович и Маскевич Вадим Миронович.
В этой курсовой работе мы попытаемся сделать "программу" для работы автосервиса. Она будет включать в себя
1. Автоматизированное рабочее место(АРМ) для механика, для заведующего по персоналу.
2. Графическая визуализация(кликабельная)
3. Расчет запчастей/рабочего времени/стоимость и период выполнение работы + доп. услуги
4. Работа с персоналом(назначение работы механику)
